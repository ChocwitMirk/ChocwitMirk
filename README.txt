Upload index.html and assets/ into the root of your public GitHub repository.
GitHub repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
Once live, enter chocwitmirkgames.com under Pages > Custom domain. Follow GitHub's displayed DNS instructions in your Wix domain DNS manager. Do not change DNS until the GitHub site works.
